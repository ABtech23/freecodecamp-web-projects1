Introduction to Java

Java is a popular, object-oriented programming language.

It is used to develop web applications, desktop software, and Android applications.

System.out.println("Hello, World!");
Variables

Variables are containers that store values.

Each variable has a type that determines what kind of value it can store.

int x = 2; String name = "Alex";
Data Types

Java has primitive data types such as int, float, double, char, and boolean.

String is a reference type used to represent text.

int x = 2; float y = 2.2f; String z = "Hello"; boolean w = true;
Operators

Operators perform operations on values and variables.

Common types include arithmetic, assignment, comparison, and logical operators.

int sum = 5 + 3; boolean result = true && false;
  • Arithmetic operators perform calculations.
  • Comparison operators compare values.
  • Logical operators combine boolean expressions.
Inputs

You can take user input in Java using the Scanner class.

Import Scanner from java.util and create a Scanner object to read keyboard input.

import java.util.Scanner; Scanner sc = new Scanner(System.in); int num = sc.nextInt();
  • nextInt() reads an integer.
  • nextDouble() reads a double value.
  • nextLine() reads a line of text.
Conditions

Conditional statements allow a program to make decisions.

Java supports if, else if, and else statements.

if (age >= 18) { System.out.println("Adult"); } else { System.out.println("Minor"); }
Loops

Loops repeat a block of code while a condition is satisfied or for a specified number of iterations.

Java provides for, while, and do-while loops.

for (int i = 0; i < 5; i++) { System.out.println(i); } while (condition) { // code to repeat }
  • A for loop is useful when the number of iterations is known.
  • A while loop repeats while its condition remains true.
Methods

Methods are reusable blocks of code that perform specific tasks.

They can accept parameters and may return a value.

static int add(int a, int b) { return a + b; }
  • Parameters provide input to a method.
  • The return statement sends a result back to the caller.
Arrays

An array stores multiple values of the same type under a single variable name.

Array elements are accessed using indexes, starting at zero.

int[] arr = {1, 2, 3, 4}; System.out.println(arr[0]);
OOP (Object-Oriented Programming)

Object-Oriented Programming is an approach based on classes and objects.

Java uses OOP to organize code, reuse functionality, and make programs easier to maintain.

class Human { String name; void speak() { System.out.println("Hello!"); } }
  • A class is a blueprint for creating objects.
  • An object is an instance of a class.
  • The four main OOP principles are encapsulation, inheritance, polymorphism, and abstraction.
Encapsulation

Encapsulation combines data and methods in a class while controlling access to the data.

Private fields and public methods can help protect an object's internal state.

class Person { private String name; public void setName(String name) { this.name = name; } public String getName() { return name; } }
  • private restricts direct access from other classes.
  • Getters and setters provide controlled access to fields.
Inheritance

Inheritance allows one class to inherit accessible fields and methods from another class.

The existing class is called the parent class, and the inheriting class is called the child class.

class Animal { void eat() { System.out.println("Eating..."); } } class Dog extends Animal { void bark() { System.out.println("Barking..."); } } Dog dog = new Dog(); dog.eat(); dog.bark();
  • The extends keyword is used for class inheritance.
  • Inheritance promotes code reuse.
  • Java classes support single inheritance of classes.
Polymorphism

Polymorphism means "many forms." It allows the same method name or interface to represent different behaviors.

Two common forms in Java are method overloading and method overriding.

class Calculator { int add(int a, int b) { return a + b; } int add(int a, int b, int c) { return a + b + c; } } class Animal { void sound() { System.out.println("Animal sound"); } } class Cat extends Animal { @Override void sound() { System.out.println("Meow"); } }
  • Overloading uses the same method name with different parameter lists.
  • Overriding lets a subclass provide its own implementation of an inherited method.
Abstraction

Abstraction hides implementation details and shows only the essential features of an object.

Java supports abstraction through abstract classes and interfaces.

abstract class Vehicle { abstract void start(); } class Car extends Vehicle { @Override void start() { System.out.println("Car starts"); } } Car car = new Car(); car.start();
  • An abstract class can contain abstract and concrete methods.
  • An interface defines a contract that implementing classes follow.
  • Abstraction helps reduce complexity.
